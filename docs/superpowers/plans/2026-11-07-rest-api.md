# REST API v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A token-authenticated JSON REST API under `/api/v1` covering login, imports, items, spots, locations and photos, documented by Scramble.

**Architecture:** `routes/api.php` (prefix `v1`, name `api.v1.`) with thin resource controllers in `app/Http/Controllers/Api/V1/`, Form Requests in `app/Http/Requests/Api/V1/`, Eloquent API Resources in `app/Http/Resources/Api/V1/`. Controllers call existing domain code (`Import::convertToItem()`, `ItemSearch`, `ExtractImport`); the panel's retry logic moves to `Import::restart()` so both doors share it. Spots are bound by code via `Spot::resolveRouteBinding()`.

**Tech Stack:** Laravel 13, Sanctum (personal access tokens), dedoc/scramble, Pest.

**Spec:** `docs/superpowers/specs/2026-11-07-rest-api-design.md`

## Global Constraints

- All commands run in Docker: `docker compose exec app …`. Never host PHP/Composer.
- Prefix `/api/v1`; route names `api.v1.<resource>.<action>`.
- Spots appear in requests and responses only as `code`; the bigint `id` never leaves the server.
- Every endpoint except `login` uses middleware `auth:sanctum` and `verified`.
- Photo rules: `mimetypes:image/jpeg,image/png,image/webp,image/gif`, `max:12288` (KB), 1–6 files.
- Paginated lists (imports, items): 24 per page, Laravel's standard resource pagination shape.
- German messages: validation from `lang/de`; fixed `409` copy as given in the tasks.
- DTOs over arrays, constructor injection (controllers get `ItemSearch` via method injection — that is the framework's injection for controllers).
- Tests in `tests/Feature/Api/`, use `Sanctum::actingAs($user)`, `Storage::fake('local')`, `Queue::fake()`; never assert literal ids.
- Before each commit: `./vendor/bin/pint --dirty` and `./vendor/bin/phpstan analyse`.
- Commit message trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

## Review Focus

1. A spot code in lower case (`k7xm`) in a path or body must resolve; a code with `0`/`O`/`1`/`I` or wrong length must 404/422 without a query. → tests in Task 2 and Task 5.
2. A photo file name from another record (or `../`-style names) must 404, never stream. → test in Task 4.
3. A second `convert` on the same import must 404 and create no second item. → test in Task 4.
4. `PATCH /items/{item}` with only `spot` must not blank title/description/search terms. → test in Task 5.
5. An unverified user holding a token (created before this rule or by tinker) must get 403 on every endpoint. → test in Task 1.
